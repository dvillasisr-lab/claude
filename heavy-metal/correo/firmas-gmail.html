Cómo ponerla

  1. Descarga este archivo y ábrelo con doble clic en Chrome (en la vista previa de la app el logo no carga).
  2. Selecciona la firma con el mouse (desde el nombre hasta el correo) y copia.
  3. Gmail → ⚙️ → Ver toda la configuración → General → Firma → Crear nueva → pega.
  4. Abajo, en “Valores predeterminados de firma”, elige cuál usar para cada dirección.
  5. Guardar cambios (hasta abajo).
